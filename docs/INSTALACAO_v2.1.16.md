# Instalação — Meu Hub + Central v2.1.16

1. Certifique-se de que está na v2.1.15 e exporte o backup do seu catálogo se houver personalizações locais.
2. Extraia `meu_hub_v2.1.16_Atualizacao_v2.1.15.zip` sobre sua pasta `meu-hub`.
3. No terminal da pasta do repositório execute `git status`, `git add .`, `git commit -m "chore: registrar FC27 Tracker v1.82.0 no hub"`, `git push`.
4. Confira o deploy no Netlify e o `version.json` do Hub. A atualização do Hub **não publica automaticamente o Tracker**.

O catálogo foi atualizado para revisão 38 e mantém a versão publicada separada da versão registrada. Não publique tokens de API.
