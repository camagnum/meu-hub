# Meu Hub v2.1.1 — instalação

Atualização a partir da v2.1.0. Faça backup do Hub e use o ZIP incremental ou completo. Preserve configurações e variáveis de ambiente Netlify (`NETLIFY_ACCESS_TOKEN`, `HUB_SYNC_KEY`). As preferências locais e credenciais de sessão não são modificadas pelos arquivos desta entrega. Publique a pasta `meu-hub` e valide o `version.json` 2.1.1 após o deploy.

FC27 Tracker v1.76.0 está **registrado** no catálogo; a publicação do FC27 é operação separada. O Hub não implanta o Tracker automaticamente.
