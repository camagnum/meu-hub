# Instalação — Meu Hub + Central v2.1.14

1. Faça backup do catálogo. Certifique-se de que o Hub atual é a v2.1.13.
2. Extraia `meu_hub_v2.1.14_Atualizacao_v2.1.13.zip` sobre a pasta `meu-hub`, preservando variáveis e configurações privadas.
3. Execute `git status`, `git add .`, `git commit -m "chore: registrar Tracker v1.81.2 no Hub"` e `git push`.
4. Verifique o deploy no Netlify. O Hub registra a v1.81.2 do Tracker, mas não presume publicação no servidor.

Se estiver em uma versão diferente, use o ZIP completo, mantendo suas configurações locais. Nunca publique tokens privados no repositório.
