# Meu Hub + Central v2.1.2 — instalação

Atualização incremental sobre a versão v2.1.1. Substitua os arquivos modificados na pasta interna `meu-hub`, sem substituir arquivos secretos de configuração. Não é necessário alterar variáveis `NETLIFY_ACCESS_TOKEN` e `HUB_SYNC_KEY`. O catálogo registra FC27 Tracker v1.76.1, mas o Tracker **não** será publicado automaticamente pelo Hub. Publique este aplicativo apenas se desejar atualizar a versão do próprio Meu Hub.
