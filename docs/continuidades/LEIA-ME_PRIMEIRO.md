# Índice dos arquivos de continuidade

Atualizado em 17/11/2026. São **21 entradas** do catálogo do Meu Hub, inclusive os dois módulos integrados.

## Como usar

1. Escolha a pasta do projeto e anexe `CONTINUIDADE_DO_PROJETO.md` ao novo chat.
2. Para um projeto ativo, anexe **também** o último ZIP/código-fonte e patches/SQL pendentes, conforme o resumo.
3. Abra a nova conversa e use o texto da seção **“Texto para colar no primeiro envio do novo chat”**.
4. Ao publicar nova versão, atualize os documentos e o catálogo do Meu Hub/Central.

**Os arquivos nesta coleção são documentação; não modificam, instalam ou substituem nenhum ZIP original de aplicativo.**
